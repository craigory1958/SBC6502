Because of the projected number of ICs needed and the difficulty of developing a single monolithic PCB, an organization of modular logic cards plugged into a backplane was chosen. Modularity allows the development and debugging of sub-functions, like memory or clock circuitry without having to re-produce a monolithic PCB.

The RCBus standard developed by [Small Computer Central](https://smallcomputercentral.com/) for homebrew 8-bit retro computing provides a turnkey backplane that will work for this project.  They offer 6 a slot backplane kit [SC701 Backplane Kit for RCBus](https://www.tindie.com/products/tindiescx/sc701-backplane-kit-for-rcbus-80pin/).  The RCBus specification was developed for Z80 based microprocessors. It is basically an 80-line bus, some lines will be repurposed for a 6502 based project.  Some lines will not be used.  The only short fall of renaming some of the bus lines is that they will be misnamed on the backplane’s silkscreen.
